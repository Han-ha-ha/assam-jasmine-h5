# 统一阿萨姆茉莉奶绿 H5

纯前端互动小游戏当前版，包含五个原主页面、固定门票分享海报状态及全部基础交互流程。

## 本地预览

在当前目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

线上地址与日后自行修改概率、重新发布的步骤见 [上线与概率修改教程.md](./上线与概率修改教程.md)。

## 基础版限制

- 使用 `localStorage` 保存本机状态及已中奖手机号；清缓存或更换设备可绕过限制，不能替代服务端防重复中奖。
- 抽奖为前端随机，无法精确控制库存或可靠防作弊。
- 分享奖励为用户手动确认，无法验证是否真实分享。
- 中奖信息通过 `mailto:` 尝试唤起邮件应用；微信内使用纯收件邮箱避免显示编码长串，并自动尝试复制完整中奖信息供用户粘贴，最终仍需用户在邮件应用中确认发送。
- 已接入客户百度统计代码 `f3af2f8610b5a7b5ff2c6c892b6d953a`，仅采集百度统计默认的访问流量数据，不上报中奖事件，也不上传姓名、手机号或身份证。
